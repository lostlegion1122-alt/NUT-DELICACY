# NJOY Google Search Console handoff

These files are for the production domain **https://nutdelicacy.in**, after client approval and deployment. The temporary client review tunnel is deliberately noindex and must not be submitted to Google.

## Files to deploy

- `sitemap.xml` goes at `https://nutdelicacy.in/sitemap.xml`. It includes the seven core pages, 21 Journal articles and 20 individual product pages (48 unique URLs).
- `robots.txt` goes at `https://nutdelicacy.in/robots.txt`. It allows public pages, JavaScript, CSS and images, and points to the sitemap. Internal working folders are excluded.
- `keyword-map.csv` documents the new article and product search targets. It is a handoff document; Google does not require this file.

## Verify ownership

1. Open [Google Search Console](https://search.google.com/search-console/) in the owner's Google account.
2. Add the Domain property `nutdelicacy.in`.
3. Copy the **actual DNS TXT record generated by Google** to the domain's DNS provider, then verify. The verification token is account-specific and cannot be invented here. If the property is already verified, keep the existing verification record.
4. Alternatively, for the URL-prefix property `https://nutdelicacy.in/`, download Google's verification HTML file and deploy it unchanged at the root, or add the exact Google-provided meta tag to the home page. Neither verification artifact is included because Google must issue the real token.

## Submit and check

1. After the approved site is deployed, confirm the production sitemap and robots URLs return HTTP 200. Confirm production responses do not contain the preview's `X-Robots-Tag: noindex`.
2. In Search Console → Sitemaps, submit `sitemap.xml`. Submit only the production domain, never the temporary tunnel.
3. Inspect Home, Collection, Peanut Butter and two new articles with URL Inspection. Use Test Live URL and Request Indexing where available.
4. Check [Rich Results Test](https://search.google.com/test/rich-results) on the fixed-price product pages. The static Product/Offer data uses actual catalog prices; no ratings, fake reviews or ₹0 prices were added. Quotation-only products intentionally omit an Offer price and may not qualify for priced product rich results.
5. Monitor Page Indexing, Sitemaps and Performance after Google crawls the new URLs. A sitemap helps discovery but does not guarantee indexing or ranking.

## Changes included

- Unique descriptive titles and meta descriptions for the core pages.
- Consistent extensionless production canonical URLs and social sharing metadata.
- Organization, WebSite, WebPage, BlogPosting, BreadcrumbList, ItemList and single-product Product/Offer structured data where applicable.
- Twelve new original articles (~600 words each) with sources, internal product links and NJOY Instagram links.
- Twenty static product detail URLs under `/shop/`, linked from the catalog and articles.
- No fabricated rankings against Pintola or MYFITNESS, unverifiable certification claims, purchase counts or customer reviews.
